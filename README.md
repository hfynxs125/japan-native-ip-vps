## "原生 IP"这个词，卖家有三种用法

混着看会得出完全相反的结论。

第一种按注册地判断。IP 段在 ARIN、RIPE 这类注册机构登记时就归属日本，不是靠 BGP 广播从别的区域借来的地址。按这个口径，一家日本机房拿到的纯数据中心 IP 也算原生。

第二种按运营商判断。IP 必须由日本本地宽带运营商（NTT、KDDI、软银等）分配给实际用户，WHOIS 归属地和机房位置一致，属性显示为住宅或 ISP，而不是数据中心。这个口径严得多，符合的 IP 数量也少得多。

第三种是卖家拆产品线时的二分法：一类叫"原生 IP VPS"，给独立站、流媒体访问用；另一类叫"ISP 原生住宅家宽 IP VPS"，专门给 TikTok、社媒账号运营用。同一个商家，两种产品能差出一倍价格。

WEPC 日本产品用的是"原生家宽""双 ISP"这类字眼，落在第二、第三种口径里，卖的是按住宅宽带属性登记的 IP。这个定位对应 TikTok 账号运营，跟"什么都能解锁"是两件事。

判断一个 IP 到底是什么，三条路：查 WHOIS 看注册机构和归属国；用 IP 属性检测工具看 type 字段和欺诈评分；拿商家提供的测试 IP 自己跑一遍。资料里没有 WEPC 日本节点的公开测试 IP，下单前找客服要一个，或者先买最小配置试几天，比看任何宣传语都直接。
